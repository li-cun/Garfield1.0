# Garfield1.0 — 加菲猫网文写作课程 Skill

基于加菲猫1314520（猫大）完整网文写作课程体系蒸馏而成的 AI 写作专家技能。搭载 93 课、超 470 小时课程材料，可提供 Mentor（导师）、Practitioner（实战）、Expert（专家）三种模式。

## 课程蒸馏方法

本技能通过 [lineage-skill](https://github.com/JuneYaooo/lineage-skill) 管线完成课程材料的蒸馏与打包：

1. **课程采集** — 收集加菲猫1314520的完整网文写作课程（93 课、约 474 小时），含逐字稿、课程摘要、案例分析
2. **结构化处理** — 提取课程核心概念、方法论、金句、证据链路，构建结构化的知识点网络
3. **多模态打包** — 生成 `course_package.json`（结构化数据）、`course_digest.md`（课程精要）、`full_transcript.md`（完整逐字稿）、`evidence_map.json`（证据索引）等参考文件
4. **Skill 生成** — 基于打包数据生成可交互的 AI Skill，支持 Mentor / Practitioner / Expert 三种交互模式

## 能做什么

| 模式 | 功能 |
|------|------|
| **Mentor** | 个性化学习引导、课程进度规划、薄弱点诊断、复习安排、课程知识点问答 |
| **Practitioner** | 将课程方法转化为可执行的工作流、清单、模板；AI 辅助大纲/细纲/成文输出 |
| **Expert** | 精确回答课程相关问题，引用课程原文，区分课程内容与模型推理 |

## 适合什么情况

- 学习加菲猫1314520的网文写作课程，需要 AI 辅助理解、回顾和练习
- 在写作实战中需要课程方法论的即时指导（写大纲、设计人设、搭建情绪框架）
- 快速检索课程中的特定概念、金句或方法论
- 新人作者入门商业化网文写作，需要系统化的学习路径和实战引导

## 课程模块

课程体系分为 **"道·法·术·器"** 四个层次，五大核心模块：

### 模块一：商业写作的底层逻辑（Why）
重塑创作者对故事、读者与商业关系的理解。涵盖读者画像分析、平台趋势判断、商业化写作的产品经理思维。

### 模块二：情绪架构与人物塑造（Core Engine）
创作的核心驱动力。涵盖核心情绪点理论、起承转合框架、人设塑造（性格图谱四维工具）、戏剧张力构建、氛围营造技巧。

### 模块三：核心创作技法（Main Techniques）
可立即上手的创作方法。涵盖大纲设计、金手指设计、爽点编排、冲突结构搭建、仿写方法论、信息差运用。

### 模块四：AI 辅助创作与工具化写作（How-to with Tools）
效率倍增器。涵盖 AI 辅助细纲生成、AI 扩展与润色、人机协作工作流。

### 模块五：实战检验与避坑指南（Practice & Review）
理论落地的练兵场。涵盖案例拆解、公开审稿分析、新人常见错误诊断。

## 安装

本技能以 Codex Plugin 形式发布，需要在 Codex 桌面应用中安装：

```bash
codex plugin add garfield1.0@personal
```

安装后新建线程即可使用 `$Garfield1.0` 触发技能。

## 使用示例

**提问**：
```
$Garfield1.0 请解释核心情绪点理论，并给我一个应用示例。
```

**期望输出**：Mentor 模式引导理解 → Expert 模式给出课程原理解释和来源引用 → Practitioner 模式提供可操作的练习建议。

**课程检索**：
```
$Garfield1.0 帮我找一下课程中关于"仿写"的所有相关内容。
```

**大纲辅助**：
```
$Garfield1.0 我正在写一个玄幻小说的开头，帮我用课程中的"噱头"方法设计3个不同的开篇方案。
```
