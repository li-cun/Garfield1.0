# 安装与使用

## 安装

本 Skill 以 Codex Plugin 形式发布，需要在 Codex 桌面应用中安装。

```bash
codex plugin add garfield1.0@personal
```

## 使用示例

### 提问
```
$Garfield1.0 请解释核心情绪点理论，并给我一个应用示例。
```

### 课程检索
```
$Garfield1.0 帮我找一下课程中关于"仿写"的所有相关内容。
```

### 大纲辅助
```
$Garfield1.0 我正在写一个玄幻小说的开头，帮我用课程中的"噱头"方法设计3个不同的开篇方案。
```
