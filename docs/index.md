# Garfield1.0 — 加菲猫网文写作课程 Skill

基于加菲猫1314520（猫大）完整网文写作课程体系蒸馏而成的 AI 写作专家 Skill。

## 课程规模

- **93 课**完整课程资料
- **约 474 小时**课程内容
- **28 MB** 全量逐字稿
- **16+** 核心概念体系

## 三大模式

| 模式 | 功能 |
|------|------|
| **Mentor（导师）** | 个性化学习引导、课程进度规划、薄弱点诊断 |
| **Practitioner（实战）** | 将课程方法转化为可执行的工作流、清单、模板 |
| **Expert（专家）** | 精确回答课程相关问题，引用课程原文 |

## 五大课程模块

1. **商业写作的底层逻辑** — 读者画像、平台趋势、产品经理思维
2. **情绪架构与人物塑造** — 核心情绪点、起承转合、人设塑造
3. **核心创作技法** — 大纲设计、金手指、爽点编排、仿写
4. **AI 辅助创作** — AI 细纲生成、人机协作工作流
5. **实战检验与避坑** — 案例拆解、公开审稿、常见错误诊断

## 快速开始

### 安装插件

```bash
codex plugin add garfield1.0@personal
```

